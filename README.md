# Nea_Headline_Media
> Этот репозиторий содержит код курсовой работы по дисциплине "Конструирование программного обеспечения"

# Тема проекта
Разработка веб‑сервиса Nea Headline Media – новостного агрегатора, который автоматически собирает новости из множества источников (СМИ), сохраняет их в единую базу данных и предоставляет пользователю удобный интерфейс для просмотра, фильтрации и поиска актуальных заголовков.

# Определение проблемы
Современные пользователи испытывают сложности с быстрым и удобным доступом к актуальным и разнообразным новостным материалам с правдивой информацией. Большое количество источников информации требует постоянного мониторинга, что занимает много времени и не всегда позволяет оперативно получать релевантные новости.
Отсутствие централизованного агрегатора, который бы автоматически собирал, фильтровал и структурировал новости из разных источников, снижает эффективность потребления новостного контента и усложняет информированность пользователей.

# Выработка требований  

## Общие требования  
Веб‑приложение должно:  
- регулярно, без участия пользователя, парсить новости из заданного списка источников (RSS, HTML, API);  
- сохранять новости в базе данных с полями: заголовок, ссылка на оригинал, источник, категория, время публикации, краткое описание;  
- предоставлять пользователю интерфейс для просмотра последних новостей, фильтрации по источнику/категории и перехода к полному тексту на сайте издания.

## Требования к получению новостей пользователем  
- Когда пользователь открывает главную страницу, он хочет видеть ленту последних новостей, отсортированных по времени, чтобы быстро понять информационную картину дня.  
- Когда пользователь интересуется конкретной темой или изданием, он хочет отфильтровать ленту по источнику или категории, чтобы убрать лишний шум и видеть только релевантные материалы.  
- Когда пользователь находит интересующий заголовок, он хочет перейти по ссылке на оригинальную публикацию, чтобы прочитать полный текст и при необходимости поделиться им.

# Архитектура системы  

## Frontend  
Пользовательский интерфейс реализован на **Django** (шаблоны HTML + CSS + JavaScript) и предоставляет страницы: главная лента новостей, фильтрация по источникам/категориям, страница отдельной новости с переходом на оригинальный ресурс.  

## Backend  
Серверная часть реализована на **Django** и включает:  
- REST/HTML‑эндпоинты для выдачи новостей из базы;  
- приложения/модули для работы с моделями `NewsItem`, `NewsSource`;  

## База данных  
В качестве хранилища используется **PostgreSQL**, в которой находятся таблицы новостей, источников и категорий.  

# Инструкция по сборке и запуску
## 1. Клонирование репозитория
```
git clone https://github.com/lorette-m/Nea_Headline_Media.git
cd Nea_Headline_Media
```
## 2. Установка зависимостей
```
python -m venv venv
```
## 3. Активация виртуального окружения
Windows:
```
venv\Scripts\activate
```
Linux/MacOS:
```
source venv/bin/activate
```
## 4. Установка библиотек
```
pip install -r requirements.txt
```
## 5. Добавить источники для парсинга
```
cd newsagg
python manage.py migrate
python manage.py init_sources
```
## 6. Запускаем парсинг
```
python manage.py parse_news
```
## 7. Запускаем сервер
```
python manage.py runserver
```
## Доступ к приложению: 
```
http://127.0.0.1:8000
```
